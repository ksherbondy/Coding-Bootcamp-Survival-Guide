# Git State Checklist

Before running a Git command you are unsure about:

```text
CURRENT BRANCH:

HEAD POINTS TO:

WORKING TREE CLEAN?:

UNTRACKED FILES?:

STAGED CHANGES?:

UNSTAGED CHANGES?:

MERGE IN PROGRESS?:

REBASE IN PROGRESS?:

REMOTE CHANGES FETCHED?:

HISTORY ALREADY SHARED?:

WHAT DO I WANT TO CHANGE?
files / staging / history / branch pointer / remote

COMMAND I THINK I NEED:

WHY:
```

Useful inspection commands:

```bash
git status
git branch
git log --oneline --graph --decorate --all
```
