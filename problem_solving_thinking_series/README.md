# Problem-Solving Thinking Series
## A Coding Bootcamp Survival Guide Lesson Series

This series focuses on the reasoning layer that most programming material skips:

```text
problem statement
        ↓
identify important words
        ↓
classify the problem
        ↓
ask what must be remembered
        ↓
choose a representation
        ↓
choose candidate tools
        ↓
write the simplest correct solution
        ↓
trace and test
        ↓
look for repeated work
        ↓
improve
```

The goal is not to memorize algorithms.

The goal is to build the reflexes that help answer:

> **"How did you know to try that?"**

# Teaching Philosophy

Students are often taught:

```text
Here is a problem.
Here is the algorithm.
Here is the answer.
```

This series instead teaches:

```text
Here is a problem.

What matters in the wording?
What kind of output is required?
What must the program remember?
Does order matter?
Do duplicates matter?
Is the input sorted?
Can we stop early?
Are we doing repeated work?
Can a data structure guarantee part of the behavior?
What is the simplest correct solution?
```

The emphasis is on **reasoning before syntax**.

# Suggested Use

These lessons can be used:

- as short instructor-led forums;
- as pre-work before coding challenges;
- as Codewars problem-solving guides;
- as pair-programming discussion prompts;
- as review material before technical interviews;
- as a reference section in a bootcamp survival guide.

Each lesson is intentionally JavaScript-friendly, but most of the reasoning applies to any language.
