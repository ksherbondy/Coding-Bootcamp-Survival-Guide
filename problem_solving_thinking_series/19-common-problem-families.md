# 19. Common Problem Families

## Objective

Classify problems into recurring families.

The exact story changes.

The underlying shape often does not.

---

# Membership Problems

Question:

> Does this value exist / have I seen it?

Tools:

```text
Set
Map
binary search if sorted
```

---

# Frequency Problems

Question:

> How many times does each value occur?

Tools:

```text
Map
Object
```

---

# Pair Problems

Question:

> Which two values satisfy a relationship?

Tools:

```text
nested loops
Set
Map
two pointers
```

---

# Range / Window Problems

Question:

> What is true about a contiguous region?

Tools:

```text
sliding window
prefix sums
```

---

# Search Problems

Question:

> Where is the target?

Tools:

```text
linear search
binary search
graph search
```

---

# Ordering Problems

Question:

> What comes before/after? What ranks highest?

Tools:

```text
sorting
heap
ordered structures
```

---

# Hierarchy Problems

Question:

> What is the parent/child relationship?

Tools:

```text
tree
DFS
BFS
```

---

# Connection / Path Problems

Question:

> What is connected, reachable, or shortest?

Tools:

```text
graph
BFS
DFS
shortest-path algorithms
```

---

# State Problems

Question:

> What can happen next?

Tools:

```text
state machine
enums/status values
transition rules
```

---

# Combinatorial Problems

Question:

> What are all possible choices?

Tools:

```text
recursion
backtracking
```

---

# Teaching Habit

After solving a challenge, ask:

> What family did this problem belong to?

That label helps recognize future problems faster.
