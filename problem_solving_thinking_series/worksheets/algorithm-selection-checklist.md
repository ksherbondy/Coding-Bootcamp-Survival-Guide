# Algorithm Selection Checklist

Check the statements that match the problem.

- [ ] Input is sorted.
- [ ] Need to find a target.
- [ ] Need two values that satisfy a condition.
- [ ] Need unique values.
- [ ] Need counts/frequencies.
- [ ] Need the first match.
- [ ] Need all matches.
- [ ] Need a contiguous substring/subarray.
- [ ] Need the longest/shortest window.
- [ ] Need top K values.
- [ ] Need every possible combination.
- [ ] Need shortest path in an unweighted graph.
- [ ] Need to process most recent first.
- [ ] Need to process arrival order.
- [ ] Need parent/child relationships.
- [ ] Need connected/reachable nodes.
- [ ] Need to merge overlapping intervals.
- [ ] Need repeated lookup by key.
- [ ] Problem repeatedly doubles or halves.
- [ ] Unknown value is an exponent.
- [ ] Need only a running maximum/minimum.
- [ ] Need to repeatedly recalculate overlapping data.
