# Edge-Case Checklist

Use only the cases that make sense for the problem.

- [ ] Empty input
- [ ] One item
- [ ] Two items
- [ ] Zero
- [ ] Negative values
- [ ] Duplicate values
- [ ] All values identical
- [ ] Already sorted
- [ ] Reverse sorted
- [ ] Target does not exist
- [ ] Target is first
- [ ] Target is last
- [ ] Exact boundary value
- [ ] Just below boundary
- [ ] Just above boundary
- [ ] Tie
- [ ] Very large input
- [ ] Very small input
- [ ] Invalid input, if the contract allows it
